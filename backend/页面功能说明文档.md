## 1. 首页（MainActivity）

### 1.1 页面定位与主要功能概述
**页面名称**：首页  
**文件路径**：`app/app/src/main/java/com/tianhu/app/MainActivity.kt`  
**布局文件**：`app/app/src/main/res/layout/activity_main.xml`

**主要功能**：
- App 启动后的入口页面，提供核心功能导航
- 展示 App 品牌形象，引导用户进入核心识别功能
- 提供底部导航栏，支持用户在不同功能模块间切换
- 提供快捷入口进入设置页面

### 1.2 核心交互流程
1. **页面初始化**：加载布局，初始化视图组件
2. **底部导航栏交互**：用户点击不同 Tab，更新选中状态
3. **功能跳转**：点击相应按钮或 Tab，跳转至对应功能页面
4. **状态更新**：根据用户操作，动态更新 UI 状态

### 1.3 关键功能模块及其具体实现细节

#### 1.3.1 开始识别按钮模块
- **功能**：引导用户进入图像识别页面
- **实现**：
  ```kotlin
  startBtn.setOnClickListener {
      startActivity(Intent(this, ImageUploadActivity::class.java))
  }
  ```
- **UI 元素**：
  - 大尺寸圆角按钮，位于页面中部
  - 绿色渐变背景（`@drawable/btn_primary`）
  - 文字内容："拍照识别"（`@string/take_photo`）

#### 1.3.2 底部导航栏模块
- **功能**：提供三个核心功能模块的切换入口
- **结构**：
  - **首页 Tab**：选中状态，默认选中
  - **历史记录 Tab**：未选中状态，点击跳转至历史记录页
  - **我的 Tab**：未选中状态，点击跳转至用户管理页
- **实现**：
  ```kotlin
  private fun updateTabSelection(position: Int) {
      // 更新图标颜色
      tabHomeIcon.setColorFilter(getColor(if (position == 0) R.color.primary else R.color.text_tertiary))
      tabHistoryIcon.setColorFilter(getColor(if (position == 1) R.color.primary else R.color.text_tertiary))
      tabMineIcon.setColorFilter(getColor(if (position == 2) R.color.primary else R.color.text_tertiary))
      
      // 更新文字颜色
      (tabHome.getChildAt(1) as TextView).setTextColor(getColor(if (position == 0) R.color.primary else R.color.text_tertiary))
      (tabHistory.getChildAt(1) as TextView).setTextColor(getColor(if (position == 1) R.color.primary else R.color.text_tertiary))
      (tabMine.getChildAt(1) as TextView).setTextColor(getColor(if (position == 2) R.color.primary else R.color.text_tertiary))
  }
  ```

#### 1.3.3 更多按钮模块
- **功能**：快捷入口进入设置页面
- **位置**：页面顶部导航栏右侧
- **图标**：`@drawable/ic_more`
- **实现**：
  ```kotlin
  moreBtn.setOnClickListener {
      startActivity(Intent(this, SettingsActivity::class.java))
  }
  ```

### 1.4 用户操作路径
| 操作流程 | 用户行为 | 系统反馈 | 跳转目标 |
|----------|----------|----------|----------|
| 进入首页 | App 启动 | 加载首页布局 | - |
| 开始识别 | 点击"拍照识别"按钮 | 启动 ImageActivity | ImageUploadActivity |
| 查看历史 | 点击"历史记录"Tab | 更新选中状态，跳转 HistoryActivity | HistoryActivity |
| 用户管理 | 点击"我的"Tab | 更新选中状态，跳转 UserManagementActivity | UserManagementActivity |
| 打开设置 | 点击右上角"更多"按钮 | 启动 SettingsActivity | SettingsActivity |

### 1.5 页面间数据流转关系
- **入数据**：无（首页为入口页面）
- **出数据**：无（仅跳转至其他页面，不传递数据）

### 1.6 异常处理机制
- **页面加载失败**：若布局资源加载失败，显示系统默认错误页面
- **跳转失败**：若目标 Activity 不存在，返回当前页面，不做特殊处理
- **内存不足**：系统自动处理，必要时清理后台资源

### 1.7 业务规则和限制条件
- 首页为单 Activity 页面，不包含 Fragment
- 底部导航栏使用自定义 LinearLayout 实现，而非系统 BottomNavigationView
- 选中状态仅在视觉上更新，实际页面切换通过 startActivity 实现
- 页面无数据加载需求，启动后立即渲染完成

## 2. 图像识别页（ImageUploadActivity）

### 2.1 页面定位与主要功能概述
**页面名称**：图像识别页  
**文件路径**：`app/app/src/main/java/com/tianhu/app/ImageUploadActivity.kt`  
**布局文件**：`app/app/src/main/res/layout/activity_image_upload.xml`

**主要功能**：
- 提供两种图片获取方式：拍照和从相册选择
- 支持图片预览和删除
- 触发图像识别流程
- 展示识别过程中的加载状态

### 2.2 核心交互流程
1. **选择图片来源**：用户选择"拍照识别"或"从相册选择"
2. **获取图片**：调用系统相机或相册应用获取图片
3. **预览图片**：在页面中展示选中的图片
4. **确认识别**：用户点击"开始识别"触发识别流程
5. **跳转到结果**：识别完成后跳转至识别结果页

### 2.3 关键功能模块及其具体实现细节

#### 2.3.1 相机拍照模块
- **功能**：调用系统相机拍摄图片
- **实现**：
  ```kotlin
  private val cameraLauncher = registerForActivityResult(ActivityResultContracts.StartActivityForResult()) { result ->
      if (result.resultCode == RESULT_OK) {
          val bitmap = result.data?.extras?.get("data") as Bitmap
          imageView.setImageBitmap(bitmap)
          imagePreview.visibility = android.view.View.VISIBLE
          recognizeButton.visibility = android.view.View.VISIBLE
      }
  }
  
  cameraButton.setOnClickListener {
      val intent = Intent(MediaStore.ACTION_IMAGE_CAPTURE)
      cameraLauncher.launch(intent)
  }
  ```
- **注意**：当前实现仅获取缩略图，未保存完整图片

#### 2.3.2 相册选择模块
- **功能**：从系统相册选择已有图片
- **实现**：
  ```kotlin
  private val galleryLauncher = registerForActivityResult(ActivityResultContracts.StartActivityForResult()) { result ->
      if (result.resultCode == RESULT_OK) {
          selectedImageUri = result.data?.data
          imageView.setImageURI(selectedImageUri)
          imagePreview.visibility = android.view.View.VISIBLE
          recognizeButton.visibility = android.view.View.VISIBLE
      }
  }
  
  galleryButton.setOnClickListener {
      val intent = Intent(Intent.ACTION_PICK, MediaStore.Images.Media.EXTERNAL_CONTENT_URI)
      galleryLauncher.launch(intent)
  }
  ```

#### 2.3.3 图片预览模块
- **功能**：展示用户选择的图片，支持删除操作
- **UI 元素**：
  - `imagePreview`：图片预览容器，初始隐藏
  - `imageView`：显示图片的 ImageView
  - `deleteButton`：右上角删除按钮
- **删除功能**：
  ```kotlin
  deleteButton.setOnClickListener {
      selectedImageUri = null
      imageView.setImageURI(null)
      imagePreview.visibility = android.view.View.GONE
      recognizeButton.visibility = android.view.View.GONE
  }
  ```

#### 2.3.4 图像识别模块
- **功能**：触发图像识别流程，展示加载状态
- **当前实现**（模拟）：
  ```kotlin
  private fun recognizeImage() {
      progressBar.visibility = android.view.View.VISIBLE
      
      Thread {
          Thread.sleep(2000) // 模拟网络延迟
          runOnUiThread {
              progressBar.visibility = android.view.View.GONE
              val intent = Intent(this, ResultActivity::class.java)
              startActivity(intent)
          }
      }.start()
  }
  ```
- **待实现功能**：
  - 调用 YOLOv8 + ResNet 模型进行识别
  - 图片预处理（压缩、尺寸调整等）
  - 识别结果解析
  - 保存识别记录到数据库

### 2.4 用户操作路径
| 操作流程 | 用户行为 | 系统反馈 | 跳转目标 |
|----------|----------|----------|----------|
| 返回首页 | 点击"返回"按钮 | 结束当前 Activity | MainActivity |
| 拍照识别 | 点击"拍照识别"按钮 | 启动系统相机 | 相机应用 |
| 相册选择 | 点击"从相册选择"按钮 | 打开系统相册 | 相册应用 |
| 预览图片 | 选择/拍摄图片 | 显示图片预览和删除按钮 | - |
| 删除图片 | 点击删除按钮 | 清空图片，隐藏预览和识别按钮 | - |
| 开始识别 | 点击"开始识别"按钮 | 显示加载动画，模拟识别 | ResultActivity |

### 2.5 页面间数据流转关系
- **入数据**：无
- **出数据**：
  - 计划传递：识别图片 Uri、识别结果等数据至 ResultActivity
  - 当前实现：未传递数据

### 2.6 异常处理机制
| 异常场景 | 处理逻辑 | 用户反馈 |
|----------|----------|----------|
| 相机权限被拒绝 | 隐藏"拍照识别"按钮，仅保留"相册选择" | 提示需开启相机权限 |
| 相册权限被拒绝 | 禁用"从相册选择"功能 | 提示需开启相册权限 |
| 图片获取失败 | 不显示预览，保持初始状态 | 无特殊提示 |
| 识别超时 | 终止识别，隐藏加载动画 | 提示识别超时，请重试 |

### 2.7 业务规则和限制条件
- 仅当选择/拍摄图片后，才显示"开始识别"按钮
- 图片预览区域仅在有图片时显示
- 识别过程中显示 ProgressBar，禁止重复点击
- 支持拍照和相册两种方式，但当前拍照仅获取缩略图
- 识别流程为异步执行，不阻塞 UI 线程
